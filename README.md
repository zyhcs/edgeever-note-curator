专为 **EdgeEver** 打造的一站式知识库整理、体检诊断与双向关联助手。

面对长期积累后出现的 **“格式碎片化、大纲断层、标签混乱、孤岛笔记无关联、缺乏重点提要”** 等痛点，Note Curator 提供了五大核心模块，帮助您秒级重构笔记质量，建立有机知识网络。

---

## 🌟 核心特性

### 1. 🩺 笔记五维健康体检与诊断 (Health Check & Audit)
* **五维量化雷达打分**：
  * 📏 **排版规范度**（Markdown 语法合规性、标题层级连贯性、空格混排检测）；
  * 📖 **内容完整度**（字数体量、大纲深度、结构完整性）；
  * 💡 **信息密度**（代码、表格、图表、关键技术点构成）；
  * 🕸️ **知识关联度**（分类标签覆盖度、是否属于孤岛笔记、全库双向引用）；
  * ⏱️ **阅读体验**（预估阅读时长、视觉呼吸感）。
* **优缺点透视分析**：精准列出“✅ 核心亮点优势”与“⚠️ 待优化不足项”；
* **一键改进处方**：清晰列出 1、2、3 项行动建议，支持一键点击直接修复。

### 2. 🧹 格式与排版净化器 (Smart Formatter & Diff View)
* **中英文混排盘古规范**：自动在中文与英文、数字、行内代码符号之间插入合规半角空格（如 `ABAP研发` ➔ `ABAP 研发`）；
* **大纲标题平滑校准**：自动消除目录断层与跳级（如防止从 `#` 直接跳跃至 `####`）；
* **代码语言自动嗅探**：扫描未标记语言的代码块，自动识别并打上 `abap`、`sql`、`json`、`python`、`javascript`、`mermaid` 等语法高亮标识；
* **空行折叠与表格整理**：自动清理连续多余空行，保持段落间标准单空行；
* **左右 Diff 视觉对照**：实时对比净化前后的清晰差异，支持“一键写入笔记”或“复制净化结果”。

### 3. ✍️ 智能内容重构与扩写 (Content Copilot)
* **⚡ TL;DR 极速备忘提炼**：一键在文首生成高亮引用卡（业务场景、关键术语、核心结论）；
* **🛠️ 异常排查与避坑指南**：自动追加常见错误代码排查、DDIC 校验与故障降级对策表格；
* **📋 参数与配置速查表**：将文中零散的配置参数自动提取转换为规范 Markdown 对比表格；
* **灵活适配**：本地规则引擎 0 Token 秒级运行；同时支持在插件设置中接入通用大模型（DeepSeek、OpenAI、Ollama 本地大模型）进行深度定制扩写。

### 4. 🕸️ 知识网络与局域图谱 (Knowledge Network & Mini Graph)
* **语义关联计算**：基于全库跨笔记的关键词交集、同名标签重合度与标题交叉引用，挖掘排名前 5 的最强关联笔记；
* **Canvas 局域星系图谱**：以当前笔记为中心星体，关联笔记为卫星环绕，连线粗细代表关联度百分比，点击节点直接跳转打开对应笔记；
* **一键注入双向链接**：一键在笔记文末生成 `### 🔗 关联知识网络` 与 `[[双向内链]]`。

### 5. 🏷️ 标签智能治理 (Tag Governance)
* **核心主题词打标推荐**：自动提取正文高频技术词汇，推荐 2~4 个标准化标签，点击即可直接打上；
* **全库高频规范库一览**：实时统计全库所有标签的使用频次，支持点击快速套用规范标签，避免冷门孤立标签。

## 🎨 界面与设计哲学

- **GitHub Primer 极客精工质感**：采用标准 GitHub 调色板与优雅微质感卡片布局；
- **全自动深浅色自适应**：无论 EdgeEver 处于白色日间主题还是黑色极客夜间主题，均能瞬间无缝贴合；
- **右下角统一插件工具坞 (Plugin Dock)**：集成精美 `🪄` 胶囊按钮，绝不遮挡其他插件或界面控件。

---

## 🚀 安装与更新

1. 打开 EdgeEver 客户端；
2. 进入 **设置 ➔ 插件市场**（或插件管理）；
3. 搜索 **Note Curator** 或 **笔记管家**，点击安装；
4. 点击右下角工具坞的 `🪄` 按钮或使用快捷键 `Cmd+Shift+C` (Mac) / `Ctrl+Shift+C` (Windows) 即可随时唤起。
